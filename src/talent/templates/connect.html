Skills come with the connection

Once connected, your AI app gets {{ skill_info|length }} Talent Search skills from the app itself: short written guides it reads when a request matches one. Nothing to add or upload, and they update with Talent Search.

Check it worked: start a new chat and ask “What Talent Search playbooks do you have?” It should name them.

Where the cards show: Cards and tables show in the Claude desktop app and the ChatGPT desktop app. Claude asks once to display them: choose Always allow. Claude Code, the Codex command line and claude.ai in a browser show the same answers as text. After you update Talent Search, quit and reopen the app so it picks up the new views.

Also want them as skill files? (Claude Code and Codex, optional)

Claude Code and Codex can also keep the skills as files in their own skills folders. One click adds them to each one found here, and Talent Search keeps them up to date each time it starts.
